# Chapter 1 · Establish revision parity

This chapter defines twenty missions for the first of fifty chapters. Each compares a specific observable behavior with a pinned source revision. “Measured” means the baseline is known, including negative results. “Open” means a dependency or missing observation still prevents closure. [Sprint results and reproduction commands](2026-11-21-first-cycle.md)

All local mutations use disposable homes, ports and databases. Tests with a provider disable paid fallback. A fixture must establish its target before sending any command. These shared prerequisites apply to each row.
